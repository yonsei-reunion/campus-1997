# 1.5 저장소 밖에 둔 자료

[목차](../고증.md)

받아서 보고 재지만 저장소 · 서버에 올리지 않는 지도 · 항공사진 · 지형 자료의 목록은 **이 파일 한 곳**에 둔다.
새로 받으면 아래 표에 한 줄을 더하고 파일 이름 · 받은 날 · 받는 법을 적는다. 다른 곳(1.1 자료 표, `reference/출처.txt`, 도구 머리말, `assets_src/*/README.md`)은 이 파일을 가리키기만 한다.

- 파일은 `assets_src/`(git 밖, `.gitignore`) 아래 자료마다 폴더 하나. `data/raw/copernicus/` 처럼 도구가 받아 두는 캐시도 같은 규칙
- 저장소에 넣지 않는 까닭은 아래 「이용 조건」. 저장소 · 고증 · 새 소식 · 이슈에는 잰 값과 「보며 잼」만 적고, 자료의 조각(잘라 낸 사진 · 지도 그림)은 올리지 않는다
- 로드뷰 · 스카이뷰 · 거리뷰 화면은 받아 두는 자료가 아니라 이 목록에 두지 않는다(도구의 캐시만 있음). 본 파노라마 id · 촬영 연월은 `reference/출처.txt`
- 게임에 쓰는 모형 · 텍스처 · 모션 캡처 · HDRI(`assets_src/models` 등)는 이 목록이 아니라 `TECH_NOTE.md` 와 `reference/출처.txt`

## 받는 법 (국토지리정보원 국토정보플랫폼 국토정보맵)

https://map.ngii.go.kr/ms/map/NlipMap.do . 목록 · 미리보기는 로그인 없이, 원본 스캔 · 수치지도는 로그인해서 신청한다(사용자가 로그인과 신청서 입력).

**화면 순서(크롬)**
- 공간정보받기 → 간편지도 검색 → 간편선택 → 항공사진 / 수치지도 / DEM / 국가기준점 / 종이지도 가운데 하나
  - 항공사진: 촬영년도(보이는 `<select>` 의 「1997년」) → 다음 → 행정구역으로 선택(서울특별시 · 서대문구) → 다음 → 대화창을 닫고 목록에서 「위치 27/18」 같은 줄의 체크칸
  - 수치지도: 수치지형도1.0 · 축척 1:5000 → 다음 → 행정구역으로 선택(서울특별시 · 서대문구) → 다음 → 목록의 「(서울078)37608078」
    - 옛 판: 그 줄의 「이력보기」 창에서 갱신일로 고름. 2009-12-15 = 2006년 측량 두 판, 2013-12-19 = 2011.03 판, 맨 위 = 최신
- 다운로드(사용자) → 신청서(사용 목적 · 생년월일 · 준수사항 동의) → 마이페이지 「신청내역관리」에서 다운로드(항공사진은 `/pd/purchs/userPurchsDtlsList2.do?listType=2`)
  - 파일: `~/Downloads` 에 `(B040)항공사진_<file_nam>.tif` · `(B010)수치지도_<도엽>_<판>_<번호>.dxf` 와 메타데이터 xml 로 떨어짐
  - 위 표의 이름으로 `assets_src/` 에 옮긴다
- 항공사진 원본은 한 번에 다섯 장까지
- 크롬 확장으로 할 때
  - 고르기: 보이는 `<select>` 에 JS 로 값을 넣고 change 를 보냄
  - 사이트의 다운로드 버튼은 누르지 않는다(페이지가 멈춘 적이 있음)
  - 로그인하면 페이지가 다시 열려 고른 것이 풀림

**다운로드 창(`nlippd.ngii.go.kr`)의 INNORIX 에이전트**
- 버전: 1.3.5.535 이상이 있어야 함
- 리눅스 설치: 사이트의 `INNORIX-Agent-20.04.deb` 를 터미널에서 `sudo dpkg -i`
  - 22.04용 deb 는 1.2.4.532라 안 됨
  - GUI 설치는 preinst 에서 멈춤
- 시작: `setsid nohup /opt/innorix-agent/innorixas start`
- 크롬 145+: `map.ngii.go.kr` · `nlippd.ngii.go.kr` 둘 다 「이 기기의 앱」(`chrome://settings/content/loopbackNetwork`)을 허용

**목록 · 미리보기를 주소로(로그인 없이, Referer 를 국토정보맵으로)**

    curl -s -A "Mozilla/5.0" -e "https://map.ngii.go.kr/ms/map/NlipMap.do" -X POST "https://map.ngii.go.kr/ms/map/airQuery.do" \
      --data "minx=949900&miny=1951500&maxx=950500&maxy=1952400&sYear=1996&eYear=1999"

- 범위: EPSG:5179(게임 원점 근처 950367.0, 1951775.1)
- 돌아오는 항목: zoneCode(사업코드) · phCourse · phNum · objectid · 범위
  - 사이트의 범위는 사진을 지도에 펴는 네모일 뿐이라 수십 m 어긋남(재는 데는 카메라 맞춤을 씀)
- 메타정보(촬영일 · 축척): `POST /ms/map/airMetaQuery.do?objid=<objectid>&layer=air&minx=0&miny=0&maxx=0&maxy=0`
- 미리보기 영상: `/search/airImage.do?file_nam=<사업코드에서 A를 뺀 숫자>00<코스 두 자리>00<번호 두 자리>&air_type=air&zone_code=<사업코드>&ph_course=<코스>&ph_num=<번호>`
  (1997년 1차는 `file_nam=199705030100<코스>00<번호>`)
- 수치지도 목록 · 이력은 `POST /ms/map/suchiQuery.do` · `/ms/map/suchiHistoryQuery.do`(화면이 보내는 값을 그대로 쓸 것)
- 1:5,000 도엽 번호: 1:50,000 도엽(15′ × 15′) 번호 다섯 자리 + 그 안을 10 × 10(1.5′)으로 나눈 001 ~ 100(북서부터 줄마다). 캠퍼스와 로터리는 `37608078` 한 장
